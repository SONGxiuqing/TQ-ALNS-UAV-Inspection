# TQ-ALNS-UAV-Inspection

This repository provides the numerical test instances and computational results supporting the study on heterogeneous multi-UAV inspection platform location and routing in chemical industrial parks under energy consumption uncertainty.

## Repository structure

### 5_Computational_Experiments

- `5.1_numerical_instances/`  
  Numerical benchmark instances and parameter settings corresponding to Section 5.1 and Table 3.

- `5.2_computational_validation_and_scalability/`  
  Exact-solver validation and scalability results corresponding to Section 5.2, Tables 4 and 5.

- `5.3_ablation_analysis/`  
  Ablation results of tailored repair mechanisms corresponding to Section 5.3 and Table 6.

- `5.4_uav_configuration/`  
  Results for homogeneous and heterogeneous UAV configurations corresponding to Section 5.4 and Table 7.

- `5.5_robustness_analysis/`  
  Robustness results over randomly generated instances corresponding to Section 5.5 and Table 8.

### 6_Sensitivity_Analysis

Sensitivity-analysis data corresponding to Section 6, Table 9, and Figures 3–5.

### 7_Case_Study

Case-study spatial input data and computational results corresponding to Section 7 and Tables 10–12.

## Data contents

The repository contains:

- numerical benchmark instances;
- run-level computational results;
- summary statistics;
- exact-solver validation results;
- ablation-analysis results;
- heterogeneous UAV configuration results;
- robustness-analysis results;
- sensitivity-analysis data;
- case-study spatial and routing data.

## Reproducibility note

The numerical data and computational results provided in this repository are intended to support independent verification of the results reported in the manuscript.

Source code is not publicly released.

## Data availability

The numerical test instances and computational results supporting this study are publicly available in this repository.
